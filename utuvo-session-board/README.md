# utuvo-session-board

Running sessions / 執行中清單 — a band above the prompt listing the Claude Code sessions busy right now on this Mac and how long each has run; over 3 hours is flagged as possibly stuck. Updates every 5 s.

Part of [UTUVO Claude Code Mods](../README.md) · [繁體中文說明](../README.zh-Hant.md)

## Install

```
/plugin marketplace add mickyyang-1407/utuvo-claude-mods
/plugin install utuvo-session-board@utuvo-claude-mods
```

The interface follows your system language (English or Traditional Chinese); set the `language` option to `en` or `zh-TW` to fix it. 介面跟隨系統語言（英文或繁體中文），也可以把 `language` 選項設成 `en` 或 `zh-TW` 固定下來。

## Test

claude plugin test utuvo-session-board
